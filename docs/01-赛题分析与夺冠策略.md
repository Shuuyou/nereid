# 赛题分析与夺冠策略

## 1. 赛题解构

**赛题九：智能体驱动的 AI 安全知识情报系统**（奇安信命题，半开放）。

命题方意图：不是再造一个通用漏洞库，而是考察——
1. 对 **AI 安全这一新兴领域**的体系化理解（漏洞不止 CVE，还有提示注入/投毒/Agent 滥用/政策法规）
2. **智能体技术**的真实运用深度（编排、自主决策、工具调用，而非套壳）
3. **工程落地能力**（自动化、时效、可演示、可部署）

## 3. 差异化武器（打冠军的关键增量）

1. **AI 资产视角情报立方体**：L1-L6 分层 × OWASP LLM/ASI × ATLAS 成熟度——现有平台无人做，命题方（奇安信）产品线正缺这个垂直视角
2. **CVE + 非 CVE 双轨**：提示注入/越狱/投毒/Agent 事件大多无 CVE——引入事件（incident）情报层 + AIID 式覆盖
3. **攻击链自动生成**：Attack Flow 风格 JSON + 中文叙述 + 可视化——评委直观看到"系统懂攻击"
4. **恶意 PoC 检测**：GitHub 上 1.9-10% PoC 含毒，可信度分级是差异化亮点
5. **中文政策源聚合**：网信办备案/TC260/GB 标准——国际平台零覆盖，中国评委共鸣
6. **影子漏洞标注**：disputed-but-exploited（如 ShadowRay CVE-2023-48022）体现情报深度
7. **用 AI 原生架构做 AI 安全情报**：系统自身即 LangGraph+MCP 式工具集——元叙事加分

## 4. 演示剧本（初稿）

1. **大屏开场**：态势总览（实时情报流滚动、L1-L6 分布、趋势）
2. **杀手级场景①**：展示一条 vLLM RCE 情报卡→点开看到自动富化的 PoC 列表+受影响资产测绘数+攻击链图+ATT&CK 映射
3. **杀手级场景②**：问答"我们内网用了 vLLM 0.8 和 Milvus 2.4，风险如何？"→ 推理链展示（分解→检索→KG 路径→答案+引用）
4. **杀手级场景③**：现场触发一次采集（新情报秒级进大屏）→ 日报自动生成
5. **收尾**：知识图谱探索 CVE→CWE→ATT&CK 多跳路径可视化

## 5. 风险

- LLM/测绘 API 依赖 → 全链路优雅降级已设计
- 采集源时效不可控（演示当天无新漏洞）→ 演示种子 + 回放模式兜底
- 评委深挖 AI 分类边界 → 分类法映射表+LLM 判读理由可解释
