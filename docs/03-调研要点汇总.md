# SOTA 调研要点汇总（2026-10-11，5 路并行联网调研）

> 详版在 Notion 竞赛文档；此处保留可落地的关键事实清单。

## A. 数据源与采集

**准实时链路（≤15min）**：cvelistV5 GitHub 仓 `git pull` + `git diff --name-status last_commit..HEAD`（官方每7min刷库）；GitHub `security_advisory` webhook（需 GitHub App）。

**快速链路（30-60min）**：GHSA REST `updated>` 增量 / OSV GCS `all.zip` modified 游标 / KEV JSON diff / HN Algolia / RSS ETag 条件GET。

**关键端点**：NVD `services.nvd.nist.gov/rest/json/cves/2.0`（key: 50req/30s；无key 5req/30s）；EPSS `api.first.org/data/v1/epss`；OSV `api.osv.dev/v1`；CVE Services `cveawg.mitre.org/api/cve/{id}`；arXiv `export.arxiv.org/api/query`（≤1req/3s）；ExploitDB `gitlab.com/exploit-database/exploitdb/-/raw/main/files_exploits.csv`；KEV GitHub 镜像 `github.com/cisagov/kev-data`（cisa.gov 直连不稳）。

**去重四层**：URL规范化哈希 → 编号union-find（CVE/GHSA/CNVD/CNNVD/EDB+OSV aliases）→ 标题指纹+SimHash64(Hamming≤3) → MinHash-LSH(128perm,J≥0.7)+向量(cos≥0.92跨语言合并)。

**源可靠性**：NATO Admiralty 思路——T1官方0.95/T2厂商0.9/T3社区0.75/T4媒体0.6/T5社交0.4 + 多源印证加分 + 结构化字段加分。

## B. 富化

**铁律**：确定性源（NVD/CVE5/KEV/EPSS/GHSA/OSV/EDB）做骨架直接锁死；LLM 只做版本区间/CPE/ATT&CK/翻译/攻击链，全部 evidence+schema校验+确定性校验器+低置信 abstain。来源权重 官方1.0>厂商0.95>聚合0.75>LLM+证据0.8>LLM0.6。

**PoC 三级**：nomi-sec `PoC-in-GitHub/{year}/{CVE}.json` + trickest/cve + nuclei-templates（YAML metadata 自带 fofa/hunter/shodan query！）→ ExploitDB codes → GitHub search 兜底。可信度：白名单(edb verified/nuclei/metasploit)=trusted；元数据+静态恶意特征（base64|sh/curl|sh/硬编码IP/IEX）→suspicious；研究示1.9-10% PoC 仓库含毒。

**测绘 query 生成**：nuclei 元数据 query > 产品名映射表 > LLM生成+语法校验。Hunter `openApi/search?api-key&search={b64url}`（500积分/天免费档）；FOFA（会员¥119/月起）；Quake（3000条/月免费）。

**论文**：S2 `graph/v1/paper/search` + OpenAlex + arXiv；query=vendor+product+漏洞类型+CWE；`/recommendations` 种子扩同类。

**映射**：CWE(NVD) → CAPEC(CWE XML Related_Attack_Patterns) → ATT&CK（CTID mappings-explorer 人工标注优先；CVE2CAPEC 推导标 derived ≤3条；LLM 兜底 0.6）。ATLAS AML.T 族另挂。

**攻击链**：MITRE Attack Flow (.afb JSON schema) 风格 {nodes,edges}+中文叙述。

## C. RAG/问答

- Embedding：Qwen3-Embedding-0.6B（多语言64.33>BGE-M3 59.56，CPU可跑，query加指令前缀）
- 稀疏：BM42（CVE/CWE/T-ID 必须词面召回）
- 向量库：Qdrant 命名向量 dense+sparse，服务端 RRF(k=60)
- Rerank：bge-reranker-v2-m3 top60→top12
- 分块：CVE条目不拆；长文 parent-child（child 300-512tok/overlap15%，+contextual prefix 检索失败率-49%）
- 多跳：路由→实体链接→分解(2-4)→并行混合检→rerank→CRAG充分性(≤2纠偏:改写+KG邻域)→KG最短路径(≤3跳)桥接→引用生成→校验
- KG：Neo4j（CVE-CWE-CAPEC-ATT&CK-Product-PoC-Paper-Item）；参数化Cypher模板（非裸text2cypher）；路径即推理链素材
- 评估：KG路径自动造多跳题（仿HotpotQA），目标≥85%

## D. Agent 编排

- LangGraph 1.x 事实标准：StateGraph+checkpoint+interrupt；AutoGen已停更并入MS Agent Framework
- 模式选型：周期任务=DAG（幂等/可重放）；交互=Supervisor-as-Tools；分析=Planner-Executor-Critic；黑板=中间态共享
- 生产陷阱：handoff踢皮球（弹跳预算）、supervisor上下文膨胀（worker只回结论）、部分失败（节点幂等+checkpoint）
