## 2. 核心设计决策

### 2.1 双链路混合智能体架构

- **周期链路 = 确定性 DAG**：采集→规范化→四层去重→富化 fan-out→校验合并→入库。节点幂等、可重放，保障"自动化程度"得分。
- **交互链路 = Supervisor-as-Tools**：QueryAgent 主智能体把"混合检索 / KG 查询 / 资产测绘 / 报告生成"封装为工具自主调用，展示"自主决策+工具调用"。
- **分析链路 = Planner-Executor-Critic**：AnalystAgent 负责日报/专题报告/攻击链，含自我校验回环，展示"多角色协作编排"。
- 运行态落 PostgreSQL TaskRun + Redis 实时节点状态；HITL 经 review_status + REST 复核队列。

### 2.2 监测时效（目标：核心链路 ≤1h，P95 ≤4h，远优于 6h 满分线）

| 层 | 源 | 机制 | 间隔 |
|---|---|---|---|
| 准实时 | cvelistV5 | git pull + diff | 10-15 min |
| 快速 | GHSA / OSV / KEV / HN | REST 增量游标 | 15-30 min |
| 标准 | NVD / RSS×20+ / seclists | REST + ETag 条件GET | 30-120 min |
| 每日 | arXiv / ExploitDB / EPSS / 政策源 | 定时批 | 每日 |

### 2.3 四层去重流水线

URL 规范化哈希 → 编号实体对齐（CVE/GHSA/CNVD/CNNVD/EDB 正则集合对齐）→ 标题指纹 + SimHash(64, Hamming≤3) → MinHash-LSH(J≥0.7)。

### 2.4 富化 ≥10 维 + 置信度合并

确定性源优先（NVD/CVE5/KEV/EPSS/OSV/GHSA/ExploitDB）→ 聚合索引（nomi-sec/trickest/nuclei-templates/Sploitus）→ 配额化搜索与测绘（GitHub/Hunter）→ LLM 结构化抽取（版本区间/CPE/ATT&CK/翻译摘要/攻击链，全部 evidence+schema 校验）→ 确定性校验器闸门 → 低置信 abstain 进复核队列。来源权重：官方1.0 > 厂商0.95 > 聚合0.75 > LLM+证据0.8 > LLM推理0.6。

### 2.5 问答 = Agentic RAG + KG 桥接

上下文化 → 路由（单跳/多跳/概览/域外）→ 实体链接 → 子问题分解 → hybrid 召回（dense top-40 + sparse top-40 → RRF k=60）→ Qwen3-Reranker 重排 top-60→12 → CRAG 式充分性检查（≤2 次纠偏）→ KG 最短路径桥接（≤3跳，序列化为可解释证据链）→ 带引用生成 → 引用校验 + 置信度 → 流式输出（答案+引用+推理链+置信度）。

### 2.6 AI 安全知识底座（差异化核心）

L1-L6 资产分层 × OWASP LLM Top10 2025 / ASI Top10 2026 威胁标签 × MITRE ATLAS 技术标注（含 Feasible/Demonstrated/Realized 成熟度）× 中文政策法规——三维情报立方体，现有平台无此覆盖。

## 3. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 编排 | LangGraph 1.x + LangChain create_agent | 显式状态图+astream 节点事件流+可重放，生态最成熟 |
| LLM | DeepSeek-V3.2（chat/reasoner） | 中文强、function calling 稳、成本极低 |
| Embedding | Qwen3-Embedding-0.6B (ONNX/CPU) | 多语言榜 64.33 超 BGE-M3，CPU 可跑，可升 4B |
| 稀疏检索 | fastembed BM42 | 精确标识符（CVE/CWE/T-ID）必靠词面召回 |
| 重排 | Qwen3-Reranker-0.6B | 中文+代码子项最佳，CPU 可跑 |
| 向量库 | Qdrant | 命名向量 dense+sparse + 服务端 RRF + payload 过滤 |
| 图谱 | Neo4j Community 5.x | Cypher 变长路径、生态成熟、可视化友好 |
| 关系库 | PostgreSQL 16 | JSONB + 递归 CTE + 任务状态 |
| 调度 | APScheduler AsyncIO + PG jobstore | 单机足够，断点续采 |
| 后端 | FastAPI + httpx + feedparser + trafilatura | 异步采集栈 |
| 前端 | Next.js 14 + Tailwind + ECharts + SSE | 实时大屏+问答流式 |
| 观测 | Prometheus + Grafana + 结构化日志 | 工程化得分点 |

## 4. 评分映射

- 监测 15 分：11 类源（远超 7 类）+ 准实时 git/webhook + 四层去重 → 优秀
- 富化 15 分：10+ 维 + 自动关联推理 + 置信度合并 → 优秀
- 问答 15 分：跨文档推理 + 多轮 + KG 桥接 + 推理链可视化 → 优秀
- 时效 5 分：核心链路 ≤1h → 优秀（≤6h 线）
- 富化准确率 5 分：官方字段锁死+校验器+abstain ≥95% → 优秀
- 问答质量：多跳≥85%（自建 KG 路径评测集证明）→ 优秀
- Agent 15 分：三层混合架构 + 工具生态 + HITL 复核队列 → 优秀
- 工程 10 分：全容器化 + CI + 监控告警 → 优秀
