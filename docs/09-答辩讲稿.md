## S1 封面（15s）

各位评委好。我们带来的作品是**捞针 · Nereid**——智能体驱动的 AI 安全知识情报系统。"捞针"取大海捞针之意：五万条情报里，帮安全团队捞出真正该看的那一根。

## S2 痛点（30s）

AI 安全风险在快速演化：提示注入、模型供应链投毒、Agent 滥用……这些新威胁**大量没有 CVE 编号**，传统漏洞库覆盖不到；而安全团队面对的又是几十上百个分散来源，人工根本盯不过来。我们的目标就是三件事：来源自动监测、富化自动关联、研判可追溯。

## S3 总体架构（40s）

四层解耦：表现层是**值班台工作台**——情报检索、漏洞详情、智能问答、知识图谱六个界面；编排层用 LangGraph 跑三种图拓扑；能力层是监测、富化、检索、关联四大模块；底座 PostgreSQL、Qdrant、Neo4j、Redis 四存储。**当前库内 50,277 条情报、52,844 个图谱节点、84,735 条边，42 个源 41 个启用**，全部无人值守滚动采集。

## S4 智能体编排（45s）

这是我们认为最体现"智能体驱动"的一页。三类任务三种编排模式：周期链路是**确定性 DAG**，采集到富化到索引逐步推进，节点幂等可重放，挂了 PostgreSQL checkpointer，崩溃后调一个 API 就能从断点续跑；交互链路是 Supervisor-as-Tools，模型自主决定调检索、调图谱还是查详情；报告链路是 Planner-Executor-Critic，生成日报。加一条新链路就是加一张子图。

## S5 情报监测（30s）

**42 个注册源覆盖 11 大类**——赛题满分线是 7 类。准实时通道是 cvelistV5 官方 git 仓 15 分钟增量拉取，**新 CVE 从披露到入库中位数约 30 分钟，金丝雀注入到可检索全链路 43.7 秒**。右侧是运行监测页，每个源的健康度、失败重试都看得见。

## S6 采集去重（30s）

四层去重：URL 哈希挡精确重复，CVE/GHSA 编号并集对齐"同一漏洞多份报告"，SimHash 抓近重复，MinHash-LSH 做全库扫重。合并不是丢弃——命中条目会补全字段、合并来源，情报卡的"×N 源确认"就是这么来的。

## S7 情报富化（35s）

八个 worker 并发跑十几个维度：CVSS/EPSS/KEV/SSVC 评分、PoC 四级可信度含恶意特征检测、CWE 到 CAPEC 到 ATT&CK/ATLAS 映射、资产测绘、论文关联、中文摘要。**官方字段锁死确定性源，LLM 只做结构化抽取**——准确率是设计出来的。

## S8 富化可信性（30s）

三条防线：官方字段只信 CNA/ADP/NVD 层级真值并记录出处；LLM 产出必须带证据过 schema 校验；**拿不准的进人工复核队列而不是硬写**。队列只收两类——高价值低置信条目和富化维度失败的条目，评委稍后在演示里能看到它只有 2 条，因为规则刻意收窄。

## S9 知识底座（30s）

结构化数据、语义向量、知识图谱协同：PostgreSQL 存权威实体，Qdrant 做稠密加稀疏混合检索，Neo4j 存实体关系。**AI 资产按 L1 到 L6 分层组织**——基础设施、模型数据、应用智能体、供应链、政策治理、滥用威胁，这是别人没有的那一层。

## S10 混合检索（30s）

为什么必须混合：CVE 编号、产品名这种精确标识符靠稀疏词项命中，"内网风险""提示注入"这种模糊问题靠稠密语义，两路 prefetch 各取前五十，RRF 融合后再过 bge 交叉编码重排，最后知识图谱做至多三跳的实体桥接。

## S11 智能问答（45s）

问答是双路径：编号直查走结构化快路径，**总时延约 3.2 秒、首 token 1.1 秒**；复杂问题走深度模式，模型自主调用检索、图谱、详情、KEV 四个工具，**多跳问题中位 16.9 秒**。每个回答带行内引用编号，可点回原始情报卡；**置信度低于阈值直接弃答**——幻觉在工程上被结构性压住。

## S12 自动化工作流（20s）

调度器常驻单进程：采集每分钟、富化每五分钟、索引每五分钟、KG 同步每十分钟、日报早八点。全部无人值守，systemd 三服务开机自愈，断电重启自动拉起。

## S13 演示·监测检索（40s）

（切换到实景截图）左边是今日值班台——待复核、高优先、新 KEV 三个队列一目了然，十四天流入趋势和实时推送流在右侧滚动；右边是情报检索页，按严重级、类型、KEV、AI 相关任意组合过滤，点击行速览、点标题进详情。

## S14 演示·富化关联（40s）

情报卡页：CVSS、EPSS、KEV、SSVC 每项评分都能展开依据——EPSS 九十九点九百分位意味着它超过百分之百同期 CVE 的被利用概率；中间是知识图谱交互；右边是影子 AI 资产暴露看板，哪些产品暴露量最大、关联哪些 CVE，模拟数据明确标注。

## S15 演示·研判输出（40s）

这是深度问答实景：用户问"内网部署 Ollama 和 Milvus 2.4 有什么风险"，系统拆实体、四路并发取证、图谱桥接，生成带引用的回答——**推理链十三步、证据十二条、置信零点九八**全部摊开给评委看。右边是报告模块，日报自动生成、STIX 2.1 标准导出。

## S16 部署工程（20s）

全容器化一键起：前端 Next.js、后端 FastAPI、四大存储加 Prometheus、Grafana。五条降级线全是真踩出来的——cisa.gov 不可达自动切 GitHub 官方镜像、GPU 驱动不匹配全链路走 CPU ONNX、LLM key 缺失模板兜底。

## S17 实验设计（30s）

评测方法学：三十条富化样本分层随机抽，对照 EPSS、KEV、NVD 官方真值逐字段核验；十二道自建问答题含多跳，人工核对标准答案与证据链。消融和对照实验标注为待执行——**我们没有把没做的实验写成做过的**。

## S18 实测结果（45s）

收口数字：**有效入库 50,277 条**；富化字段级**准确率 99.17%、召回 100%**；问答**整体命中率 97.9%、多跳 95.8%、引用通过率 83.3%、推理链完备 100%**；更新时效 cvelistV5 中位约 30 分钟，端到端金丝雀 43.7 秒。失败案例也写在这——个别回答引用编号超出引用集，是生成侧噪声，我们已在前端做口径校验和未引用候选折叠。

## S19 创新点（30s）

六个差异化：AI 资产视角情报立方体；CVE 加非 CVE 双轨，事件和政策是一等公民；攻击链自动生成；PoC 四级可信度含恶意检测；层级真值源富化；LangGraph durable execution 断点续跑——每一条都能现场演示，不是 PPT 功能。

## S20 收尾（15s）

捞针 · Nereid 想做的事一句话：**让每一条漏洞，自己走完从发现到决策的路**。它不是又一个漏洞列表，而是一群替安全团队值夜班的智能体。谢谢各位评委，请批评指正。
