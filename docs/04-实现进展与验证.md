## 修复过的关键缺陷

1. **KEV 目录 URL 误合并**：34 条 KEV 共享目录 URL → url_hash 把不同 CVE 并成一条。修复：实体对齐(CVE/GHSA)优先级提到 URL 哈希之上 + `_id_compatible` 守卫 + KEV 条目改用 cve.org 独立 URL
2. **simhash 溢出**：simhash 库返回无符号 64 位 → BigInteger 越界。修复：`& (2^63-1)`
3. **单条 flush 失败污染整批**：每条入库改 `begin_nested()` SAVEPOINT 隔离
4. **SSVC datetime 进 JSONB**：`_json_safe` 统一序列化
5. **子 Agent 文件冲突**：后台子 Agent 中途覆写了部分 enrichment 文件，已逐一修复字段契约（extract_ids/ai_layer/lang 判定）
6. **S2 限流拖慢**：Semantic Scholar 429 → 进程级熔断跳过
7. **Qdrant 假死**：客户端 1.19 与服务端 1.13.6 不兼容 → 锁定 `qdrant-client>=1.13,<1.14`

## 运维要点（新踩坑）

- **Qdrant FD 耗尽**：容器默认 nofile=1024，RocksDB 段+索引撑爆 → compose 已加 `ulimits.nofile=65535`，再未假死
- **pkill -f 自杀**：`pkill -f "uvicorn app.main"` 会匹配含该字符串的 bash 命令行 → 用 `scripts/start_api.sh`（pgrep|xargs）
- **heredoc 残留进程**：`python3 - <<EOF` 的 cmdline 是 `python3 -`，pkill 按名字杀不掉 → 改用 `scripts/batch_ops.py`（具名进程）
- **stale .pyc**：文件 mtime 回置时 Python 用旧字节码 → 批量改文件后 `find -name __pycache__ -exec rm -rf`
- **Notion 同步**：系统 python3 用 requests（urllib 被中间盒断连）；`scripts/build_notion_doc.py` 全量重建
